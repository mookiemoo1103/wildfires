# Active Wildfire Placefile — AguaceroWx

## Install
Extract this ZIP and upload/replace these files in the root of the separate
`mookiemoo1103/wildfires` GitHub repository, preserving the folder paths:

- `generate_wildfire_placefile.py`
- `active_wildfires.txt` is generated by GitHub Actions; do not hand-edit it.
- `assets/fire_icon.png`
- `.github/workflows/update-wildfires.yml`

## Generate the placefile
1. Open the repository's Actions tab.
2. Select **Update Active Wildfire Placefile**.
3. Click **Run workflow**.
4. Confirm the run finishes with a green Success status.
5. Open `active_wildfires.txt` and confirm it starts with the Title, RefreshSeconds,
   Font, IconFile and then one or more `Icon:` records.

## Add to AguaceroWx
In AguaceroWx open **Edit Layers → Add Layer → Custom Layer → Live link** and paste:

`https://raw.githubusercontent.com/mookiemoo1103/wildfires/main/active_wildfires.txt`

Continue, name it, and choose **Save & Load**. Make sure the layer is visible and
that **Show icons** is enabled.

## Important
- This version deliberately uses simple point icons only, to make the placefile
  easy to parse and load. It omits perimeter polygons until point rendering is
  confirmed in AguaceroWx.
- The flame icon is loaded from the `assets/fire_icon.png` path in this repository.
- The incident feed is NIFC WFIGS and covers the United States, not all of North America.
- GitHub Actions runs every five minutes (GitHub may delay scheduled runs).
  `RefreshSeconds: 10` controls the client refresh request; it does not make the
  underlying source update every 10 seconds.
- Only records categorized as wildfires and not reported contained, controlled,
  out, or 100% contained are plotted. Source status can lag field conditions.
